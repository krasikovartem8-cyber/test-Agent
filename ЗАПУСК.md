# Как запустить агента

Все команды выполняются в **PowerShell**, по одной. Оператор `&&` в Windows PowerShell 5.1 не работает, поэтому не объединяйте строки.

## Один раз при первой настройке

### 1. Перейти в папку проекта

```powershell
cd C:\Users\АРТЁМ\Desktop\browser-agent
```

### 2. Установить зависимости

```powershell
npm run setup
```

Команда ставит пакеты и скачивает запасной браузер Chromium. Занимает пару минут.

### 3. Создать файл настроек

```powershell
copy .env.example .env
```

### 4. Вписать ключ

```powershell
notepad .env
```

Заполните строки в зависимости от того, чей ключ используете, и сохраните файл.

**Anthropic (рекомендуется, ключ лежит в `C:\Users\АРТЁМ\Desktop\api.txt`):**

```
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=sk-ant-...
```

**OpenAI:**

```
LLM_PROVIDER=openai
OPENAI_API_KEY=sk-proj-...
OPENAI_MODEL=gpt-4.1
OPENAI_SUBAGENT_MODEL=gpt-4.1-mini
```

На аккаунте должны быть деньги: у API OpenAI нет бесплатного тарифа, при нулевом балансе приходит ошибка `429 credit_balance_exhausted`.

**Бесплатный OpenAI-совместимый шлюз** (Groq, OpenRouter, Gemini, локальная Ollama) — примеры адресов и моделей лежат в самом `.env.example`. Модель обязана уметь вызывать инструменты.

### 5. Проверить доступ к модели

```powershell
npx tsx scripts/check-api.ts
```

Зелёная галочка означает, что ключ принят и модель отвечает. Красные строки читаются так:

| Ответ | Что значит |
|---|---|
| `HTTP 401` или `403` | ключ неверный либо модель недоступна аккаунту |
| `429 credit_balance_exhausted` | на счету нет средств |
| `Connection error`, таймаут | API недоступен с этой сети, нужен VPN |

## Каждый раз, когда нужно поработать

### 1. Перейти в папку

```powershell
cd C:\Users\АРТЁМ\Desktop\browser-agent
```

### 2. Запустить

```powershell
npm run dev
```

Откроется окно браузера, а в терминале появится шапка с названием модели и приглашение:

```
👤 You:
```

### 3. Дать задачу

Кликните по **окну PowerShell**, чтобы оно стало активным, напишите задачу после `👤 You:` и нажмите Enter. Писать в адресную строку браузера не нужно: туда попадёт поисковый запрос, и ответит Google, а не ваш агент.

Примеры задач:

```
На market.yandex.ru найди беспроводные наушники дешевле 3000 рублей и выпиши три варианта с ценами
```

```
Найди на hh.ru вакансии Python-разработчика в Москве с зарплатой от 200 тысяч и опиши три самые интересные
```

Признак того, что задача ушла агенту: в терминале сразу побегут строки `🔧 Using tool: navigate` с аргументами, а страницы в браузере начнут переключаться сами.

## Что происходит во время работы

| Значок в терминале | Что означает |
|---|---|
| `💭` | рассуждения модели |
| `🔧 Using tool` | вызов инструмента и его аргументы |
| `Result:` | что вернул браузер |
| `🔍 DOM sub-agent` | ответ субагента, читающего страницу целиком |
| `❓ Agent asks` | агенту нужен ваш ответ, напишите его и нажмите Enter |
| `✅ SUCCESS` | задача выполнена, ниже итоговый отчёт |

Вмешиваться в браузер во время работы не нужно. Баннеры, выбор города и всплывающие окна агент закрывает сам.

## Команды внутри агента

| Команда | Действие |
|---|---|
| `/reset` | забыть историю разговора, начать с чистого листа |
| `/tabs` | показать открытые вкладки |
| `/exit` | выйти и закрыть браузер |

Ctrl+C тоже корректно завершает работу.

## Запуск с параметрами

Задача сразу из командной строки:

```powershell
npm run dev -- --task "Найди на wildberries.ru кружку с котом дешевле 500 рублей"
```

С записью видео браузера в папку `recordings`:

```powershell
npm run dev -- --record
```

Показывать результаты инструментов целиком, без сокращений:

```powershell
$env:VERBOSE="1"; npm run dev
```

## Если что-то пошло не так

**`Лексема "&&" не является допустимым разделителем операторов`** — вы объединили две команды. Выполняйте по одной.

**`⚠ No API key found`** — файл `.env` не создан или строка с ключом пустая. Вернитесь к шагам 3 и 4.

**`API error (Connection error)` с повторами** — нет связи с API. Включите VPN и проверьте доступ командой из шага 5.

**Страница `403` про подозрительную активность** — так Яндекс реагирует на скрытый режим браузера. Запускайте без флага `--headless`, обычным `npm run dev`.

**Агент вошёл не в тот аккаунт или просит логин** — профиль браузера хранится в папке `.browser-profile`. Залогиньтесь в нужных сервисах один раз в открытом агентом окне, дальше сессия сохранится.

## Проверка без ключа

Эти команды работают вообще без API и полезны, чтобы убедиться, что браузерная часть жива.

Показать, что агент «видит» на странице:

```powershell
npm run smoke -- https://hh.ru
```

Прогнать весь цикл со скриптованной моделью вместо настоящей:

```powershell
npx tsx scripts/mock-run.ts
```

Проверить типы:

```powershell
npm run typecheck
```
